資料集

以下五份內建資料依真實研究情境設計，數值為程式模擬產生，僅供學習使用。每份都附編碼簿，可直接在實驗室開啟。

匯入你自己的資料

  1. 在 Excel 中整理成整齊資料：第一列是欄位名稱，每列一個觀察單位，每欄一個變數。
  2. 欄位名稱建議用英文或拼音、不含空白（例如 sbp_wk12），論文中再換成完整名稱。
  3. 缺失值留空，或填 NA。類別可以用文字（drug）或數字（1）。
  4. 另存新檔為「CSV（逗號分隔）」或 Tab 分隔文字檔，然後在實驗室按「上傳 CSV／TSV」。也可以直接從 Excel 複製範圍貼上。
  5. 載入後檢查欄位類型：以數字編碼的類別（例如分期 2/3/4）請點一下欄位，改成「類別」。

公開資料庫

練習進階分析或準備論文時可以找真實資料。下載成 CSV 或 TSV 後即可匯入；部分資料庫需要申請或完成倫理訓練。

  • Vanderbilt Biostatistics Datasets臨床與流病教學資料集，多數可直接下載 CSV。初學最推薦。
  • NHANES美國國民健康與營養調查，橫斷面資料，含問卷、檢驗與體檢。
  • cBioPortalTCGA 等癌症基因體研究；臨床資料（含存活時間）可下載 TSV。
  • NCBI GEO基因表現與高通量定序資料庫。
  • UCI Heart Disease經典的心臟病資料，適合練習邏輯斯迴歸。
  • PhysioNet／MIMIC-IV加護病房電子病歷，需完成訓練並申請。
  • Dryad生態與演化研究論文附帶的原始資料。
  • GBIF全球生物多樣性物種出現紀錄。
  • 政府資料開放平臺台灣衛生、環境與人口統計開放資料。
  • Kaggle Datasets使用者分享的資料，品質不一，使用前請確認來源。
